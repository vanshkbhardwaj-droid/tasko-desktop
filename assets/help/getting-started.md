# Getting started locally

Tasko keeps the working database on this computer. Add a customer, schedule a visit, create a document, and make a backup before you need one.

## Fast keyboard actions

- Command or Control + K searches local records and navigation.
- Command or Control + Shift + Space opens quick capture.
- Drag an appointment in the weekly calendar to reschedule it. Conflicts are blocked before saving.

## Working offline

Local records, invoice PDFs, calendar exports, search, backups, and the local assistant do not require a connection. Team syncing is an intentional separate action.
