# Bundled local language model

`tasko-qwen2.5-0.5b-q3_k_s.gguf` is the Qwen 2.5 0.5B Instruct model in GGUF Q3_K_S quantization, distributed from the community GGUF conversion repository for Qwen. It is loaded by node-llama-cpp inside the installed application for offline local drafting, short summarisation, and grounded classification.

The model is not customer data and is not padding: it is required for Tasko’s offline Copilot mode. The source model is licensed under the Qwen research licence terms supplied with its upstream model. Keep attribution and model licences with every redistributed installer.
